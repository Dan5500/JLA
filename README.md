# JLA: Jarvis-Like Assistant
This project aims to be a personal project of mine - as there are many other people who have made personal ai assistants for themselves. What makes this project different from chatgpt.com, is the ability for this one to have its own "brain". It will be able to remember things, have a personal identity, and own memories that the user can view and edit. Along with having its own brain, it will help the user with anything it asks for, having access to the user's file system (under specific guidelines and requesting permission when necessary). Imagine Jarvis, but without access to Iron Man suits.
